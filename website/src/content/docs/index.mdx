## Why bidsmith

<p class="section-intro">Four reasons teams move their Google Ads out of the dashboard and into version control.</p>

<CardGrid>
  <Card title="Every change is a pull request" icon="approve-check">
    Edit a file, open a PR, get a teammate to review. No more "who paused
    that campaign last Friday?" — Git tells you.
  </Card>
  <Card title="Preview before you spend" icon="magnifier">
    `bidsmith plan` shows you exactly what will change in Google Ads before
    a single euro moves. No surprises.
  </Card>
  <Card title="One source of truth" icon="document">
    Your `.bid` files describe the campaigns you want. bidsmith makes
    Google Ads match. Run it twice — the second run does nothing.
  </Card>
  <Card title="Designed for marketers" icon="rocket">
    No SQL, no scripting, no API tokens to copy-paste every week. Edit
    plain text files in any editor, commit, push, apply.
  </Card>
</CardGrid>

## How it works

<p class="section-intro">From a plain-text file to a live campaign in three commands.</p>

<div class="how not-content">
  <article class="how__step">
    <span class="how__num">1</span>
    <h3 class="how__title">Write</h3>
    <p>Describe the campaigns, ad groups, and keywords you want in <code class="how__cmd">.bid</code> files — and version them in Git like any other code.</p>
  </article>
  <article class="how__step">
    <span class="how__num">2</span>
    <h3 class="how__title">Preview</h3>
    <p>Run <code class="how__cmd">bidsmith plan</code> for a line-by-line diff of what will change. Nothing touches your account yet.</p>
  </article>
  <article class="how__step">
    <span class="how__num">3</span>
    <h3 class="how__title">Apply</h3>
    <p>Run <code class="how__cmd">bidsmith apply</code> and bidsmith makes Google Ads match your files — exactly what the plan showed.</p>
  </article>
</div>
