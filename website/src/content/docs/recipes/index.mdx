## More coming

This section grows from real questions. If you have a "how do I…?"
that isn't here, [open an issue](https://github.com/chrmod/bidsmith/issues/new) —
it's the fastest path to a recipe being written.

A non-exhaustive list of recipes that are on the way:

- Bulk-add keywords from a spreadsheet
- Set a different bid for one ad group
- Schedule a budget change for next Monday
- Find which campaigns reference a shared set
- Import a single campaign (not a whole account) via `bidsmith refresh`
- Run bidsmith from GitHub Actions on every merge
