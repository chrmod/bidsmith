A **campaign budget** caps how much one or more campaigns can spend per
day. Every campaign references exactly one budget.

<Aside type="tip" title="Micros, again">
  `amount_micros` is in micros — one millionth of the account currency.
  €50.00/day = `50_000_000`. The trailing six zeros are the tell.
</Aside>

## Example

```hcl
resource "google_ads_campaign_budget" "summer" {
  name            = "Summer 2026"
  amount_micros   = 50000000          # €50/day
  delivery_method = "STANDARD"
}
```

A budget shared by multiple campaigns:

```hcl
resource "google_ads_campaign_budget" "brand" {
  name              = "Brand Protection"
  amount_micros     = 200000000       # €200/day
  delivery_method   = "STANDARD"
  explicitly_shared = true
}
```
