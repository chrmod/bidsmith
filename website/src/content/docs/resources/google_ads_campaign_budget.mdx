A **campaign budget** caps how much one or more campaigns can spend —
per day by default, or over a fixed flight if you set
`period = "CUSTOM_PERIOD"`. Every campaign references exactly one budget.

<Aside type="tip" title="Micros, again">
  `amount_micros` is in micros — one millionth of the account currency.
  €50.00/day = `50_000_000`. The trailing six zeros are the tell. Same
  for `total_amount_micros`.
</Aside>

## Example

```hcl
resource "google_ads_campaign_budget" "summer" {
  name            = "Summer 2026"
  amount_micros   = 50000000          # €50/day
  delivery_method = "STANDARD"
}
```

A budget shared by multiple campaigns:

```hcl
resource "google_ads_campaign_budget" "brand" {
  name              = "Brand Protection"
  amount_micros     = 200000000       # €200/day
  delivery_method   = "STANDARD"
  explicitly_shared = true
}
```

## Lifetime budgets

Most budgets are daily: `amount_micros` is the average you're willing to
spend each day, and Google keeps the monthly total under about 30.4 times
it. A **custom-period** budget works the other way round — you name a
total for the whole flight and Google paces it:

```hcl
resource "google_ads_campaign_budget" "q3_flight" {
  name                = "Q3 Launch Flight"
  period              = "CUSTOM_PERIOD"
  total_amount_micros = 150000000     # €150 for the whole run
}
```

The two amounts are alternatives, not a pair. A daily budget says
`amount_micros`; a `CUSTOM_PERIOD` one says `total_amount_micros` and
Google Ads ignores any daily amount you set beside it. `validate` holds
you to that, so a budget can never quietly spend on a figure nobody
meant.

<Aside type="caution" title="A budget's period is fixed at creation">
  `period` and `type` can't be edited once the budget exists — Google Ads
  refuses the change, and bidsmith won't plan one. If a file says
  `period = "DAILY"` (the default) but the budget it adopts is a
  custom-period one, `plan` says so rather than reporting a clean run:
  the daily amount in the file is being ignored by Google. To change a
  budget's period, make a new budget and point the campaign at it.
</Aside>

<Aside type="caution" title="Sharing a budget takes one extra line">
  `explicitly_shared` defaults to `false`, and pointing a **second**
  campaign at a budget that isn't explicitly shared is an error Google
  Ads rejects — *"Only explicitly shared campaign budgets can be used
  with multiple campaigns."* Nothing in the file hints at it, because the
  default is applied for you.

  If you want two campaigns on one budget, say `explicitly_shared = true`
  as above. If you wanted them independent, give each its own budget —
  that's usually what you want, since a shared budget means the campaigns
  compete for the same daily spend.

  `plan` catches this before it sends anything and names the budget and
  the campaigns. Worth letting it: the raw API rejection lands on the
  *second* campaign, while the first reports a misleading "Resource was
  not found" and the batch takes every unrelated change down with it.
</Aside>
