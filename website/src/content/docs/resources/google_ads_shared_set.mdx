A **shared set** is a reusable list of negative keywords. Define it
once, link it to multiple campaigns via
[`google_ads_campaign_shared_set`](./google_ads_campaign_shared_set/),
and edit it in one place when something changes.

<Aside type="tip">
  Shared sets are the right answer when more than one campaign needs
  the same negative-keyword list. For one-off negatives that only
  apply to a single campaign, use
  [`google_ads_campaign_criterion`](./google_ads_campaign_criterion/)
  with a `negative_keyword` block.
</Aside>

## Example

A shared negative list of "free / DIY / used" terms:

```hcl
resource "google_ads_shared_set" "value_seekers" {
  name   = "Value-seeker negatives"
  type   = "NEGATIVE_KEYWORDS"
  status = "ENABLED"

  negative_keyword {
    text       = "free"
    match_type = "BROAD"
  }

  negative_keyword {
    text       = "diy"
    match_type = "BROAD"
  }

  negative_keyword {
    text       = "used"
    match_type = "BROAD"
  }
}
```
