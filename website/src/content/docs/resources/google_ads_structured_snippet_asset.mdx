A **structured snippet asset** is a predefined `header` (from Google's
fixed list — "Brands", "Features", "Services", "Types", …) followed by a
short list of `values`. Google can show it below a search ad to preview
what you offer, e.g. **Features: Cookie Banner Blocker, Ad Blocker,
Tracker Blocker**.

<Aside type="note">
  The `header` must be one of Google's supported snippet headers for your
  language. A snippet is only the *content* — link it to a campaign with
  [`google_ads_campaign_asset`](./google_ads_campaign_asset/) (or an ad
  group with [`google_ads_ad_group_asset`](./google_ads_ad_group_asset/))
  using `field_type = "STRUCTURED_SNIPPET"`.
</Aside>

## Example

```hcl
resource "google_ads_structured_snippet_asset" "features" {
  header = "Features"
  values = ["Cookie Banner Blocker", "Ad Blocker", "Tracker Blocker"]
}
```
