A **customer asset** links an asset to the *entire account*. Once linked,
the asset can appear with any ad in the account that's eligible to show
it. It's the account-wide counterpart to
[`google_ads_campaign_asset`](./google_ads_campaign_asset/) (one campaign)
and [`google_ads_ad_group_asset`](./google_ads_ad_group_asset/) (one ad
group).

<Aside type="note">
  The `asset` reference can point at any asset type bidsmith models —
  [`google_ads_call_asset`](./google_ads_call_asset/),
  [`google_ads_sitelink_asset`](./google_ads_sitelink_asset/),
  [`google_ads_callout_asset`](./google_ads_callout_asset/), or
  [`google_ads_structured_snippet_asset`](./google_ads_structured_snippet_asset/) —
  and `field_type` must match the asset's kind. Call extensions are the
  most common account-wide link.
</Aside>

## Example

Link the `main_phone` call asset to every ad in the account:

```hcl
resource "google_ads_customer_asset" "main_phone_link" {
  asset      = google_ads_call_asset.main_phone.id
  field_type = "CALL"
  status     = "ENABLED"
}
```
