A **callout asset** is a short phrase — like "Free & Open Source" or
"24/7 Support" — that Google can append below a search ad to highlight a
selling point. Unlike a sitelink, a callout is not clickable and has no
landing page; it's pure copy that helps the ad render larger.

<Aside type="note">
  A callout is only the *content*. Link it to a campaign with
  [`google_ads_campaign_asset`](./google_ads_campaign_asset/) (or an ad
  group with [`google_ads_ad_group_asset`](./google_ads_ad_group_asset/))
  using `field_type = "CALLOUT"` to make it eligible to show.
</Aside>

## Example

```hcl
resource "google_ads_callout_asset" "free_open_source" {
  text = "Free & Open Source"
}
```
