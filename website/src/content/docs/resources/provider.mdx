The **provider** block declares which Google Ads account bidsmith is
operating against. Every `.bid` project needs exactly one `provider`
block; convention is to put it at the top of your top-level
`account.bid` (or in the first file of a single-file project).

<Aside type="note">
  `customer_id` is optional here. For live commands the target account
  resolves in order: `GOOGLE_ADS_CUSTOMER_ID` env var →
  [`bidsmith.toml`](/bidsmith/recipes/manage-multiple-accounts/) in your
  project → this provider block → your saved sign-in. Leave it out of the
  provider block to keep `.bid` files account-agnostic and target them
  with a per-folder `bidsmith.toml` — ideal when one set of campaigns is
  applied to several accounts. (`export` also accepts `--customer-id` /
  `--login-customer-id`; `plan` and `apply` do not — use `bidsmith.toml`
  or the env vars for those.)
</Aside>

## Example

```hcl
provider "google_ads" {
  customer_id       = "1234567890"
  login_customer_id = "9876543210"
}
```
