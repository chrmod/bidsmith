A **campaign shared set** is the join between a
[`google_ads_campaign`](./google_ads_campaign/) and a
[`google_ads_shared_set`](./google_ads_shared_set/) — it tells one
campaign to apply one shared list.

To attach the same list to N campaigns, declare N
`google_ads_campaign_shared_set` resources.

## Example

Apply the `value_seekers` shared set to the summer search campaign:

```hcl
resource "google_ads_campaign_shared_set" "summer_value_seekers" {
  campaign   = google_ads_campaign.summer_search.id
  shared_set = google_ads_shared_set.value_seekers.id
  status     = "ENABLED"
}
```
